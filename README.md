# F&B Control – Prototipo Web (Streamlit + SQLite)
Convierte tus libros de Excel en una app ligera.
## Ejecutar
```
python -m venv .venv
# Windows: .venv\Scripts\activate
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```
1) Administración → Inicializar base de datos
2) (Opcional) Cargar datos de ejemplo
3) Usa Insumos/Movimientos y Consulta de existencias
